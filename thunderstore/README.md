# Minimap

A round minimap in the corner of the screen, styled like the game's own HUD.

It shows a picture of the arena with its walls and rocks, enemies (a different shape per tier, so the big ones stand
out), bosses, objectives and their pieces, pickups, teammates, and map features like geysers, tornadoes and portals.
Objectives and pickups appear once someone in your party has seen them, and anything the game points at from the edge
of the screen sticks to the edge of the minimap. MoreEvents targets show up too if you have that mod.

The map turns with the camera and moves out of the way when the game's HUD needs that corner.

## Keys

- M: hide or show
- = and -: zoom in and out

Size, corner, shape, zoom and which things to show can all be changed in the mod's config.

## Multiplayer

Only install it if you want a minimap yourself; nobody else needs it. If the host has it too, found objectives are
shared with everyone running it.
